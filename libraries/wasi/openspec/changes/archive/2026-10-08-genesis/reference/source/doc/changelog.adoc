== Changelog

What changed in wasi in each version of webcpp, newest first, one line
per change. "Unreleased" is what the next version brings. The release notes
of every version are on webcpp's index page.

[#wasi-changelog-unreleased]
=== Unreleased

// tag::unreleased[]
* Fixed a status outside 100-599 answering 200 OK; it now answers an
internal error.
* Fixed a content type viewing the request's method or target not being
sent.
* Fixed a content type the host refused being dropped silently; it now
answers an internal error.
* Added the `WEBCPP_WASI_NO_EXCEPTIONS` configuration macro, defined
automatically or by the developer.
* Updated the documentation: wasmtime's versions, the by-hand build, escaping
exceptions and a changelog.
* Added `WEBCPP_NO_EXCEPTIONS`, which disables wasi's exceptions with every
webcpp library's.
// end::unreleased[]
