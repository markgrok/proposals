Example

Collaborative cursors with WebRTC actions

Send a small message when the pointer moves, then draw a cursor for each peer. This is the same pattern used by the live cursors on this site.

Broadcast pointer positions

This sketch sends coordinates as fractions of the viewport. The rendering functions and color helper are yours to implement. For a shared canvas or document, use coordinates relative to that surface instead.

Pointer events can fire faster than you need to send them. Throttle updates in your app and interpolate received positions for smooth movement. Remove a peer’s cursor when onPeerLeave fires.
