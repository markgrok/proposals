# Working on webcpp's proposals

Read the superproject's `AGENTS.md` first
(<https://github.com/webcpporg/webcpp/blob/main/AGENTS.md>), then
`CONTRIBUTING.md`. This file holds only what is specific to this repository.

- **Several OpenSpec roots.** There is no `openspec/` at the repository's root: the organization
  is `organization/openspec/`, each library `libraries/<name>/openspec/`. Every `openspec`
  command runs from the root it concerns.
- **The checks.** `openspec validate --all --strict --no-interactive` in each root, then
  `python3 tools/proposals.py readme`, `python3 tools/proposals.py check` and
  `python3 tools/proposals_test.py` at the repository's root, as CI runs them.
- **Agent skills** are in `.agents/skills/<name>/SKILL.md`: OpenSpec's own (`openspec-*`,
  generated by OpenSpec 1.10.0 and adapted to the several roots) and webcpp's
  (`webcpp-openspec-proposal`, `webcpp-reference-status`, `webcpp-text-and-commits`). They point
  to the rules and never replace them; where one disagrees, `CONTRIBUTING.md` and the
  organization's specification win.
